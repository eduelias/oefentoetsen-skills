# oefentoetsen-skills

Public repo (MIT): Claude Code skills that write and mark practice tests in the `oefentoetsen` player (sibling repo; the formats live in its `README.md`, not here).

- Only skills: no hooks, servers, commands or installers in the plugin manifest.
- Skills are generic. Nothing about one child, one school or one home network.
- Do not copy the player's format reference into a skill; point at the player's README so there is one source.
- A skill names a tool in the player (`tools/check.js`, `tools/report.js`) only if that tool exists there.
